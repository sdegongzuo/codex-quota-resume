# 自动续跑与提前压缩需求

确认日期：2026-10-12。本文记录用户已确认的重新设计要求；它描述目标行为，不代表当前 0.1.0 已实现。

## 目的

Codex 桌面会话因五小时额度耗尽而中断时，自动登记尚未完成的任务，在额度恢复后继续原会话。提前缩小活动上下文，减少恢复后继续执行所需的输入 token；用户通过列表控制哪些任务继续。

按等待后提示词缓存可能失效的情况设计，不假定一定命中缓存，也不宣称缓存一定失效。减少输入 token 不等于可以按相同比例延长订阅额度，实际效果需观察。

## 已确认的行为

| 项目 | 要求 |
| --- | --- |
| 自动续跑 | 默认开启，用户可以关闭 |
| 收集单位 | 一个原会话对应一项任务；同一会话的新中断作为新的事件记录，避免重复入队 |
| 收集条件 | 原会话因五小时额度耗尽而中断，任务仍待继续；一般网络错误或仅周额度耗尽不能冒充该条件 |
| 续跑位置 | 在原会话继续，保持原任务和最新用户要求 |
| 任务列表 | 显示会话名称、中断时间、预计续跑时间、当前状态和自动续跑开关 |
| 手动控制 | 每项可关闭，也有总开关；关闭后保留记录，可重新开启 |
| 提前压缩 | 活动上下文占用达到实际上下文窗口的 60% 时，趁仍有额度完成一次实际压缩 |
| 阈值 | 可配置；60% 是首轮试运行值，先观察再调整 |
| 压缩时机 | 在可安全执行压缩的边界处理，避免打断正在执行的工具操作 |
| 压缩确认 | 验证真实压缩完成，保留压缩前后占用数据；模型写总结不能替代压缩 |
| 压缩内容 | 保留任务目标、最新要求、已完成工作、未完成事项、必要证据和下一步 |
| 防重复压缩 | 每次由低于阈值增长到达到阈值触发一次；压缩后仍高于阈值时不连续重复触发 |
| 恢复缓冲 | 服务返回的额度恢复时间后等待 120 秒，再检查实际许可 |
| 恢复重查 | 未恢复时每 60 秒重查；连接失败或许可未知不能视为恢复 |
| 发送前判断 | 已手动恢复的跳过，已完成的标记完成，明确停止的关闭自动续跑；出现新指令时取消旧中断的待发送动作，按最新状态重新判断 |
| 多任务 | 按中断时间排队，逐个续跑；不能只是循环串行发送、实际让多个会话同时运行 |
| 状态恢复 | 列表、开关、压缩和发送状态持久保存；插件重启、休眠后恢复检查 |
| 防重复发送 | 同一次中断先持久记录发送占位；结果不确定时停止自动重发，向用户显示待核对状态 |

默认继续指令表达：继续完成原会话尚未完成的用户任务，从中断处接着执行，遵循最新要求与已有授权；任务完成或需要用户信息时停止。

## 状态与边界

列表至少区分：等待额度、已关闭、排队、正在续跑、已完成、已停止、需要用户输入、连接不可用、发送结果待核对。压缩另有状态：未达到阈值、等待执行边界、压缩中、已完成、额度不足、接口不支持、结果待核对。

额度错误能够证明运行中断，不能独立证明用户整个任务未完成。收集为待续跑候选，结合最新轮次及可用任务状态判断；缺少明确证据时不得显示为“已确认任务完成”。

默认开启以插件正常加载且必要 hooks 已经用户信任为前提。持久化的手动关闭设置优先于默认值，启动 hook 不能重新打开用户关闭的总开关或单项开关。

压缩与额度恢复分别调度：平时达到 60% 就处理压缩，不能等到额度已经耗尽才开始。额度先耗尽或压缩失败时记录原因，恢复后评估是否先压缩再续跑。压缩不可用时仍提供原会话续跑，并明确显示压缩能力不足。

电脑关机时无法执行；Codex 关闭或连接不可用时保留记录，重连后核对。账号不匹配、原会话无法确认或已归档时暂停处理，不能换到其他会话发送。缺少重置时间时显示未知，不伪造倒计时。

## 首轮观察

观察 3～5 次完整运行、压缩、中断和恢复过程。记录实际窗口、压缩前后 token、压缩耗时和次数、恢复时间、发送及开始运行时间，以及遗漏要求、重复读文件或重复工作的情况。

每轮阈值建议调整 5 个百分点。低阈值是否节省总消耗需要结合压缩成本、缓存命中和重复工作判断；首次采用 60%，不自动改值。

## 验收要求

1. 新配置默认开启；用户关闭后，重启及 hooks 均不恢复开启。
2. 真正五小时额度中断进入列表一次，其他错误不误入；关闭项目保留记录。
3. 达到 60% 时在仍有额度的条件下完成真实压缩，观测到压缩结果并验证任务信息延续；重复事件不导致重复压缩。
4. 恢复时间加 120 秒前不发送；之后仍须确认实际使用许可，未恢复按 60 秒重查。
5. 续跑消息发往原会话，多个会话按顺序启动，已手动恢复或停止的不会重复启动。
6. 重启、休眠、断连、账号变化及发送结果不确定时保留可解释状态，不重复发送。
7. 用真实桌面会话和原始接口回执验证；模拟接口通过不能代替自然额度耗尽及恢复验收。
