# 额度显示和待续跑列表修复

- 面板显示五小时和一周剩余额度、北京时间恢复日期及采集时间。缺失值显示未知，空窗口显示数据不可用，读取失败保留上次样本并提示，90 秒未更新显示过期。
- 默认列表按会话合并并隐藏本轮完成、已停止和已替代记录；“显示历史”展示每次中断，保留各自开关和操作身份。
- 总开关仅关闭自动动作；后台仍只读采集额度。打开面板会确保 worker 启动，互斥机制防止重复 worker。`stop` 命令仍可安全停止后台。
- 已登记会话不因离开最近聊天目录而停止读取；本机 rollout 白名单元数据也用于补充发现。元数据扫描仍限最近 200 个候选文件及监测起点之后的主桌面会话，不承诺无限追溯。
- 补充发现用于收集中断，不能替代发送授权：目录外或目录不可用时仍禁止自动发送，等待桌面目录重新确认目标。

验证包含额度转换及异常响应、关闭开关后只读采集、目录外收集但不发送、同会话历史记录保留，以及现有完整测试。真实自然耗尽到恢复续跑、浏览器视觉验收需分别确认，不能由测试通过代替。
